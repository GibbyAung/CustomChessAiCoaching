# RISK_REGISTER.md

## Key Risks & Mitigations

### Technical Risks

- **WASM performance:** Early benchmarking, fallback to server-side engine
- **AI explanation quality:** Human validation, fallback to pre-written explanations
- **Mobile performance:** PWA optimization, simplified mobile UI

### Product Risks

- **User adoption:** Early user testing, focus on unique value
- **Feature complexity:** Progressive disclosure, beginner mode
- **Competition:** Focus on UX, rapid iteration, niche targeting

### Business Risks

- **Timeline overruns:** Strict MVP scope, milestone tracking
- **API cost escalation:** Only open-source/free APIs used
- **Legal/compliance:** Use open-source components, privacy by design

## Monitoring

- Weekly technical reviews
- Bi-weekly user feedback
- Monthly risk register updates
