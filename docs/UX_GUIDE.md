# UX_GUIDE.md

## User Experience Guidelines

### User Journeys

- **First-time user:** Onboarding, tutorial, first game with coach
- **Returning user:** Dashboard, progress review, new challenges

### Design Principles

- Clarity and simplicity
- Progressive disclosure (show advanced features only when needed)
- Immediate feedback for all actions
- Accessibility (WCAG 2.1 AA compliance)
- Mobile-first, responsive design

### Accessibility

- Keyboard navigation and screen reader support
- High-contrast mode
- Large touch targets
- Color-independent information

### UI Components

- Chessboard: interactive, highlights, drag-and-drop/click-to-move
- Coach panel: hints, explanations, learning tips
- Move history: clickable, annotated
- Game controls: undo, hint, resign, settings
